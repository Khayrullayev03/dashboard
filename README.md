# Портфолио IT-администратора

**Сайт:** https://khayrullayev03.github.io/dashboard/

Статичный сайт в ASCII/терминальном стиле под алой луной: открывается двойным кликом по `index.html`,
сервер и сборка не нужны. Опубликован через GitHub Pages: любое изменение, отправленное в `main`,
появляется на сайте через 1–2 минуты (`.github/workflows/publish.yml` копирует `main` в ветку
`gh-pages`, из которой GitHub показывает сайт). Ветку `gh-pages` вручную не правьте.

## Страницы

| Адрес | Страница |
|---|---|
| `#home` | **Главная** — только логотип: по нему постоянно проходят глитч-сбои (сдвиг строк, «битые» символы, расслоение цвета); наведение или клик — сильный сбой. За логотипом — огромная алая луна. |
| `#services` | **01. Услуги** — у каждой услуги большая анимированная картинка (блоки по очереди слева и справа). |
| `#about` | **02. О себе** — карточка системного администратора (имя, должность, профиль, страна, уровень, связь, счётчики), шесть направлений работы с анимированными значками, навыки по уровням, подробные плитки навыков. Опыт и сертификаты появятся, когда будут заполнены. |
| `#info` | **03. Инфо** — анимированная карта мира с точкой посетителя, его IP, место и координаты. |
| `#contact` | **04. Контакты** — карточки с анимированными картинками: Telegram, почта, Instagram. |

Старые адреса (`#office`, `#skills`, `#terminal` и др.) открывают соответствующие новые страницы.
Работают кнопки браузера «Назад/Вперёд»; на каждой странице есть ссылка `← меню`.

Над услугами — карточки «30+ компаний» (число — `clients` в `js/data.js`) и число услуг.

Новая услуга — новый объект в массиве `services`: `title`, `desc`, `points` (строки или `{ ru, uz, en }`)
и `scene` — имя анимации из `js/scenes.js` (`servers`, `network`, `windows`, `linux`, `monitoring`, `pc`, `html`,
`cctv`, `cloudpbx` и др.). `feature: "office"` вместо картинки показывает 3D-схему офиса, `feature: "voip"` — схему IP-телефонии.

## Навыки (`js/data.js`)

- `skillLevels` — список навыков из резюме, сгруппированный по уровню (`advanced` — продвинутый,
  `intermediate` — средний и т. д.). На странице «О себе» показывается блоком `~/skills.txt`:
  заголовок уровня со шкалой и «чипы» навыков. Новый навык — новая строка в `items`
  (просто текст или `{ ru, uz, en }`).
- `skills` — подробные плитки с анимациями (клик открывает описание, что умею, и пример).

## Инфо: IP, место и координаты посетителя

- **Внешний IP**, город, провайдер и координаты — из публичного сервиса ipwho.is (запасной — ipapi.co).
  Запрос уходит из браузера посетителя, только когда он открыл страницу «Инфо».
- **Локальный IP** проверяется через WebRTC без внешних запросов. Современные браузеры его скрывают
  (показывают маску вида `xxxx.local`) — тогда так и написано: «скрыт браузером».
- Если сервис недоступен (например, внутри песочницы claude.ai внешние запросы запрещены), место и
  координаты показываются примерно по часовому поясу, без IP.
- Также показываются часовой пояс, время, браузер, система, экран и язык — всё видит только сам посетитель.
- На карте: полоса радара, перекрестие через точку посетителя, «пинг»-кольца, табличка с координатами
  и сигнал от вашего города (`profile.location` в `js/data.js`).

## Оформление, языки, звук, пасхалка

- **Языки** — `[ru|uz|en]` в шапке. Тексты интерфейса — в `js/i18n.js`, содержимое — в `js/data.js`.
- **Liquid Glass** — карточки из «жидкого стекла»: сильное размытие и насыщенность фона, блик по верхнему краю,
  светящийся край с алым отблеском луны; блик следует за курсором. Тема одна — тёмная.
- **Шрифт** лежит в `fonts/`: в версии с Google Fonts нет рамок и блоков, из-за чего ASCII-рисунки
  на iPhone и Mac «съезжали».
- **Звук** — кнопка с динамиком (по умолчанию выключен).
- **Пасхалка** — ↑↑↓↓←→←→ B A включает «режим матрицы».
- Если в системе включено «уменьшение движения», анимации не запускаются сами; их можно включить
  кнопкой `[ ▶ смотреть ]`.

## Что можно дополнить (`js/data.js`)
