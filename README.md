# dashboard

Персональный сайт-портфолио: системный администратор, IT-инфраструктура, сети, СКС, телефония.

**https://khayrullayev03.github.io/dashboard/**

Чистый HTML, CSS и JavaScript без сборки и зависимостей. ASCII-графика, карточки в стиле Liquid Glass,
три языка (ru / uz / en).

## Запуск

Открыть `index.html` в браузере. Или локальный сервер:

```bash
npm start
```

## Статистика и оценки

Раздел «Кто заходил» и блок оценки работают через [Supabase](https://supabase.com) (бесплатный тариф).
Пока ключи не заданы, раздел и оценка скрыты.

1. Создать проект в Supabase.
2. SQL Editor → вставить `supabase/schema.sql` → Run.
3. Project Settings → API: скопировать Project URL и публичный ключ (anon / publishable) в `assets/js/config.js`.

Хранится анонимно: источник перехода, город по часовому поясу, тип устройства, раздел. IP не сохраняется.
Ссылки с меткой источника: `https://khayrullayev03.github.io/dashboard/?from=telegram`.

## Производительность

На слабых устройствах (до 4 ГБ памяти, до 4 потоков или режим экономии трафика) сайт сам включает облегчённую
графику: без размытия стекла, с более редкой анимацией фона, а карта Kaspersky загружается по кнопке. Если во время
работы кадров меньше ~38 в секунду, облегчённый режим включается автоматически. Переключатель — внизу страницы.

## Поиск Google

В `index.html` есть разметка schema.org (Person и ProfessionalService), в корне — `sitemap.xml`.
Чтобы сайт быстрее попал в Google: [Search Console](https://search.google.com/search-console) → добавить ресурс
`https://khayrullayev03.github.io/dashboard/` → подтвердить мета-тегом → отправить `sitemap.xml`.

## Гостевая книга

Работает без регистрации и своего сервера:

1. Гость пишет никнейм и комментарий → сообщение уходит в бесплатный сервис [ntfy.sh](https://ntfy.sh)
   (тема `guestbook.topic` в `assets/js/config.js`). На сайте комментарий появляется сразу.
2. Раз в час GitHub Action (`.github/workflows/publish.yml`, шаг «Guestbook») забирает новые сообщения, проверяет их
   (никнейм 2–32 символа, текст 2–500, без ссылок) и сохраняет в `assets/data/guestbook.json` — комментарии остаются
   на сайте навсегда. ntfy.sh хранит сообщения 12 часов, поэтому Action должен быть включён.

- Кто оставил: никнейм, время и текст — в `assets/data/guestbook.json` (история изменений видна в GitHub).
- Уведомления на телефон: приложение ntfy (Android/iOS) → «Подписаться» → имя темы из `config.js`.
- Удалить комментарий: открыть `assets/data/guestbook.json` на GitHub → удалить запись → Commit. Если комментарий ещё
  не сохранён (меньше часа), сначала Actions → publish → Run workflow, потом удалить.
- GitHub отключает расписание, если в репозитории 60 дней не было изменений, — тогда Actions → publish → Enable.

## Безопасность

- Content Security Policy (мета-тег в `index.html`): скрипты только с этого сайта, без встроенного JS, `eval` и плагинов.
- Защита от копий: `assets/js/boot.js` и начало `assets/js/main.js` перенаправляют на оригинальный адрес, если сайт
  открыт на чужом домене. При переезде на свой домен добавьте его в список в обоих файлах.
- Защита от встраивания в чужие страницы (iframe): сайт внутри фрейма не показывается.
- Карта Kaspersky открывается в песочнице (`sandbox`), без права управлять страницей.
- Supabase: запись только через функции `add_visit` и `add_rating` с лимитами по IP (IP хранится только как хеш с
  секретной солью), один голос с одного IP, общий потолок записей в час и в сутки. После изменения схемы выполните
  `supabase/schema.sql` в SQL Editor ещё раз.
- GitHub Action закреплён по хешу коммита.
- Права на код и контент: `LICENSE` (все права защищены).
