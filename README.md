# dashboard

Персональный сайт-портфолио: системный администратор, IT-инфраструктура, сети, СКС, телефония.

**https://khayrullayev03.github.io/dashboard/**

Чистый HTML, CSS и JavaScript без сборки и зависимостей. ASCII-графика, карточки в стиле Liquid Glass,
три языка (ru / uz / en).

## Запуск

Открыть `index.html` в браузере. Или локальный сервер:

```bash
npm start
```

## Статистика и оценки

Раздел «Кто заходил» и блок оценки работают через [Supabase](https://supabase.com) (бесплатный тариф):
проект «dashboard», регион Франкфурт. Бесплатный проект засыпает после 7 дней без запросов — тогда в панели
Supabase нажать Restore (пока сайт посещают, он не засыпает).

1. Создать проект в Supabase.
2. Project Settings → Integrations → GitHub: подключить этот репозиторий, рабочая папка `.`, ветка `main`,
   включить **Deploy to production**. Тогда миграции из `supabase/migrations` применяются к базе сами при каждом пуше.
   Без интеграции: SQL Editor → вставить файл из `supabase/migrations` → Run (файлы можно запускать повторно).
3. Project Settings → API Keys: скопировать Project URL и публичный ключ (publishable `sb_publishable_…` или
   legacy anon) в `assets/js/config.js`. Секретный ключ (secret / service_role) на сайт не ставить.

Хранится анонимно: источник перехода, город по часовому поясу, тип устройства, раздел. IP не сохраняется.
Ссылки с меткой источника: `https://khayrullayev03.github.io/dashboard/?from=telegram`.

## Производительность

- Карточки без живого размытия фона (`backdrop-filter`): оно пересчитывалось бы каждый кадр поверх анимированного фона.
  Размытие осталось только у шапки и уведомлений.
- Облегчённый режим включается сам: до 4 ГБ памяти, до 4 потоков, режим экономии трафика или браузер без аппаратной
  видеокарты (WebGL на процессоре). Во время работы — если кадров меньше ~50 в секунду. Переключатель — внизу страницы.
- 3D-логотип на WebGL запускается только с настоящей видеокартой, иначе — лёгкая CSS-версия.
- Фоновое ASCII-поле рисуется в 1×, луна — до 1.5×; ASCII-сценки обновляют только изменившиеся строки.
- Все анимации останавливаются, когда блок не виден или вкладка неактивна.

## Гостевая книга

Комментарии хранятся в Supabase (таблица `guestbook`) — сразу и навсегда, пока вы их не удалите.

- Сайт пишет через функцию `add_comment`: никнейм 2–32 символа, текст 2–500, без ссылок, не больше 3 комментариев
  за 10 минут и 15 в сутки с одного IP, повтор того же текста не создаёт дубль. Читает через `list_comments`.
- Модерация: Supabase → Table Editor → `guestbook`. Скрыть — поставить `hidden = true`, удалить — Delete row.
- Уведомления о новых комментариях приходят в приложение ntfy (Android/iOS). Имя темы хранится только в базе
  (таблица `secrets`, строка `notify_topic`), в коде сайта его нет.

## Безопасность

- Content Security Policy (мета-тег в `index.html`): скрипты только с этого сайта, без встроенного JS, `eval` и плагинов.
- Защита от копий: `assets/js/boot.js` и начало `assets/js/main.js` перенаправляют на оригинальный адрес, если сайт
  открыт на чужом домене. При переезде на свой домен добавьте его в список в обоих файлах.
- Защита текста (`assets/js/boot.js` + CSS): нельзя выделить, скопировать, сохранить и распечатать страницу; при
  копировании в буфер попадает подпись с адресом сайта. Разрешено копировать только из полей ввода и контактов
  (класс `allow-copy`). Это защита от обычных посетителей — текст всё равно есть в исходном коде страницы.
- Защита от встраивания в чужие страницы (iframe): сайт внутри фрейма не показывается.
- Карта Kaspersky открывается в песочнице (`sandbox`), без права управлять страницей.
- Supabase: запись только через функции `add_visit` и `add_rating` с лимитами по IP (IP хранится только как хеш с
  секретной солью), один голос с одного IP, общий потолок записей в час и в сутки. Изменения схемы — новым файлом в
  `supabase/migrations` (применится при пуше через GitHub-интеграцию).
- GitHub Action закреплён по хешу коммита.
- Права на код и контент: `LICENSE` (все права защищены).
